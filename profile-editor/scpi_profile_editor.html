SCPI Profile Editor

Configuration tool for USB SCPI Logger (ESP32-OTG)

Select Preset

How it works: Upon connecting the instrument via USB, the logger firmware reads profile files from the SD card folder /sdcard/profiles/. It matches the *IDN? response substring with match.idn_contains and checks if the USB Vendor ID matches match.vid. If they match, the logging configuration is applied.

Recommended Rigol Instruments for the Logger

The USB SCPI Logger running on ESP32-OTG with USB Host support can read data from most standard bench instruments. Below is a list of recommended Rigol models grouped by purpose:

Category Model Series Key Features Example SCPI Queries for the Logger
DC Electronic Load Rigol DL3000 series
(DL3021, DL3021A, DL3031)		 Battery discharge logging, power supply testing. 150V, 40A/60A, up to 350W. :MEASure:VOLTage:DC? (voltage)
:MEASure:CURRent:DC? (current)
:MEASure:POWer:DC? (load power)
Bench Power Supply Rigol DP800 series
(DP832, DP831, DP811)		 Up to 3 isolated outputs. Industry standard for device power rails and current logging. :MEASure:VOLTage? CH1 (voltage CH1)
:MEASure:CURRent? CH1 (current CH1)
:MEASure:POWer? CH1 (power CH1)
Bench Power Supply Rigol DP900 series
(DP932A, DP932U, DP932E)		 Modern replacement for DP800 with color touchscreen and compact footprint. Same SCPI as DP800 (e.g. :MEASure:VOLTage? CH1 etc.)
Digital Multimeter Rigol DM3058 / E
(5.5 digit)		 Economic and highly stable bench DMM. Fast reading speed. :MEASure:VOLTage:DC? (DC voltage)
:MEASure:CURRent:DC? (DC current)
:MEASure:RESistance? (resistance)
Digital Multimeter Rigol DM3068
(6.5 digit)		 Higher accuracy, reading speed, and advanced configuration options. Same SCPI commands as DM3058.
* Tip: For programmable loads and PSUs, it is recommended to set select_single: false, which records all configured channels/measurements as columns in each line. For multimeters, select select_single: true.
